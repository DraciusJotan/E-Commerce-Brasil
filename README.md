# E-Market Brasil

Loja on-line fictícia de **consumo consciente**, criada para o desafio prático do Comitê de Inovação Sustentável e Consumo Responsável.

É uma página única (HTML, CSS e JavaScript puros, sem dependências) que funciona direto no navegador.

## Funcionalidades

- **Preço por uso:** cada produto mostra quanto custa a cada vez que é usado, não só o preço.
- **Alugar ou comprar?:** calculadora interativa que compara o aluguel por diária com a compra e mostra a partir de quantos dias comprar compensa.
- **Checkout com cadeado (Trava da Necessidade):** antes de pagar, três perguntas (preciso? cabe no orçamento? vou usar?). O cadeado só abre quando as três fazem sentido.
- **Geladeira de 7 dias:** o item fica reservado por uma semana para a pessoa decidir com calma.
- **Caixa que volta:** embalagem retornável com R$ 10 de cashback e entregas agrupadas por bairro.
- **Tema claro e escuro**, layout responsivo para celular e animações (que respeitam a opção "reduzir movimento" do sistema).

## Como abrir

Abra o arquivo `index.html` no navegador. Para publicar, qualquer hospedagem de site estático serve (por exemplo, GitHub Pages).

## Estrutura

```
index.html   página completa (estilos e scripts incluídos)
img/         fotos dos produtos
```

## Observações

Empresa, produtos, preços e números são fictícios. Algumas fotos de produtos foram geradas por IA para ilustrar.
